FONTS FOLDER
============
Put the file "fonts-bundle.js" in this folder (this folder sits next to index.html).

How to make fonts-bundle.js (no tools needed):
1. Open the app, click "Fonts..." (next to any Font dropdown).
2. Click "Add font folder..." (for example C:\Windows\Fonts) or "Add font file(s)...".
3. Click "Save fonts to app folder...". Your browser downloads fonts-bundle.js.
4. Move that file into this folder (replace the old one if there is one) and reopen the app.

Only .ttf, .otf and .woff fonts work. Keep the total under about 160 MB (a few hundred fonts at most);
loading hundreds of fonts makes the app slower to start, so add the ones you actually use.
Fonts you add with "Add font folder..." are also remembered by the browser, but some browsers clear that storage; this file is the permanent copy.
